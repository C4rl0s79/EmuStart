# Edytor wyglądu

Start → **Wygląd (logo, czcionki, kolory)** albo Ustawienia → Edytor wyglądu.
Panel otwiera się z boku ekranu, a zmiany widać od razu na karuzeli systemów lub
liście gier.

| Pad | Działanie |
|---|---|
| ↑ / ↓ | pozycja |
| ← / → | zmiana wartości |
| LB / RB | zmiana o 5 kroków |
| A | przełącz ekran pod spodem (systemy / gry) |
| Y | przenieś panel na drugą stronę |
| X | przywróć domyślną wartość |
| Start (dwa razy) | przywróć wszystko |
| B | zapisz i zamknij |

## Co można ustawić

**Logo** — wysokość i szerokość logo tytułu na liście, wielkość logo systemów
w karuzeli i odstęp między nimi, logo systemu i zaznaczonej gry nad listą gier.

**Lista i podgląd** — wysokość wiersza listy gier, wysokość wiersza w ustawieniach,
szerokość listy, wysokość okładki i zrzutu (zawsze równe), liczba linii opisu.

**Wielkość czcionek** (osobno) — cały interfejs, lista gier, tytuł gry, metadane,
opis gry, nazwa systemu, informacje o systemie, menu/okna/ustawienia, pasek
podpowiedzi, pasek górny.

**Kolory** — kolor akcentu (8) i tło (6 wariantów).

**Inne** — tytuły gier jako logo (Clear Logo) oraz **Wygląd zapisywany**: dla
profilu (taki sam na każdym komputerze) albo dla tego komputera.
