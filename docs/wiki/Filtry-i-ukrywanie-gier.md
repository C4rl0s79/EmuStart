# Filtry i ukrywanie gier

## Filtry listy (X)

Na liście gier **X** otwiera filtry: szukaj (klawiatura ekranowa), gatunek,
dekada, liczba graczy, region, producent, pokaż (wszystkie / tylko lokalne /
tylko przypięte / grane / niegrane), sortowanie. Przy każdej opcji widać, ile gier
zostanie. Filtry zapamiętywane są osobno dla każdego systemu.

## Ukrywanie wersji (Ustawienia → Ukrywanie gier)

Na podstawie oznaczeń w nazwach No-Intro/Redump/MAME. Każda grupa osobno,
**osobno dla każdego profilu**:

| Grupa | Oznaczenia |
|---|---|
| Wersje rozwojowe | Beta, Proto, Prototype, Possible Proto, Alpha, Debug, location test |
| Dema i wersje promocyjne | Demo, Kiosk, Promo, Sample, Trial, Preview |
| Pirackie i przeróbki | Pirate, hack, bootleg |
| Nielicencjonowane | Unl, Aftermarket, Homebrew |
| Programy i BIOS-y | Program, BIOS |
| Klony arcade | warianty gier arcade (zostaje wersja główna) |

Rewizje (Rev 1, Alt) zostają — to pełne wersje gier. Gry nie znikają z dysku ani
z biblioteki, tylko z listy; liczby gier w karuzeli uwzględniają ukryte.
