# Sterowanie

EmuStart obsługuje się padem; klawiatura i mysz działają zastępczo.
Podpowiedzi przycisków na dole ekranu można klikać — wszystko da się zrobić samą myszą
(np. na komputerze bez pada). Przy wyborze folderu: Y — wpisanie ścieżki z klawiatury.

## Wszędzie

| Pad | Klawiatura | Działanie |
|---|---|---|
| D-pad / lewa gałka | strzałki | nawigacja |
| A | Enter / spacja | wybierz |
| B | Esc / Backspace | wstecz / zamknij |
| Start | F2 / Tab | menu (Ustawienia, Wygląd, Grafiki, Profile, Pady, Skanuj, Wyjdź) |

## Karuzela systemów

| Pad | Działanie |
|---|---|
| ← / → | poprzedni / następny system |
| A | lista gier systemu |
| **A przytrzymane** | opcje systemu: logo, nazwa, emulator, pobranie emulatora, grafiki, skan, ukrycie |

## Lista gier

| Pad | Klawiatura | Działanie |
|---|---|---|
| A | Enter | graj |
| **A przytrzymane (0,6 s)** | — | opcje gry: emulator dla tej gry, wczytanie zapisu, metadane, okładka/zrzut/logo, opis z sieci |
| X | X | filtry: szukaj, gatunek, dekada, gracze, region, producent, sortowanie |
| Y | Y / P | przypnij / odepnij (gra zostaje w pamięci podręcznej na stałe) |
| LB / RB | PgUp / PgDn | strona w górę / w dół |
| LT / RT | Home / End | poprzednia / następna litera |

## Ekran pobierania gry

| Pad | Działanie |
|---|---|
| X | „Graj teraz (z sieci)” — start bez czekania na koniec kopiowania |
| B | anuluj |

## W grze

| Pad (przytrzymany LB +) | Działanie |
|---|---|
| **LB + A** | menu (własne menu emulatora, gdy je ma na pada — RetroArch, DuckStation, PCSX2, PPSSPP; inaczej [menu w grze](Menu-w-grze) EmuStart) |
| **LB + Y** | zapisz w kolejnym slocie |
| **LB + X** | zapisz w wybranym slocie |
| **LB + ↑ / ↓** | slot zapisu w górę / w dół |
| **LB + RB** | przyspieszenie |
| **LB + R3** | zrzut ekranu |
| **LB + L3** | nagrywanie (gdzie emulator je ma) |

LB trafia też do gry (emulator czyta pada sam).

Przycisk Xbox/PS nie jest używany — przechwytują go emulatory i Windows.

## Klawiatura ekranowa

W polach tekstowych (nazwy, wyszukiwanie, hasło RetroAchievements) pojawia się
klawiatura ekranowa obsługiwana padem; ⇧ zmienia wielkość liter. Działa też
zwykła klawiatura.
